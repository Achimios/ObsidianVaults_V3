# 寻路

前往目标点：
- 听即时指令或玩家调整朝向
- 听玩家或分析战场局势
- 找标志物

没目标时：
- 找拓扑出口
- 沿着海岸线或悬崖边缘
- 室内寻找光亮处、室外
- 有枪声的方向
- 安全区域吸引
- 危险区域排斥
- 视野中心权重高
- 边缘自然衰减

没敌人时：
- 自然扫视
- 平滑转向
- 趋向安全位置
- 保持合理姿态

# 攻击目标选择
### 1vN威胁大，或血量少，感知到快死的时候
打死一个算一个，攻击敌方血量最少、移动最慢、距离最近，综合来说最容易死的那个

### 绕后偷屁股
热力图上根据易受攻击度形成的簇（如俩互相距离近，离我也近的人），产生更强的热点，射击顺序图，优先偏向此热团，再转向其他目标
但若有人回头看到我，且距离近，根据威胁度，可先攻击此敌人

### 高级决策
- 收益趋势- 哪个血量少，哪个离你准星近，哪个暴露面积大，哪个移动速度慢，哪个空间距离近子弹延迟小，
- 威胁趋势 - 哪个已经发现你了，哪个朝向更对着你，哪个离你近，哪个攻击力高，对方是爆发高还是持续强，


# 欧拉角旋转

# 各向异性和角度限制

### 机械云台、直升机、战斗机等
**马氏距离**
 某些云台Yaw弱，热图降低权重，来计算瞄准路径
**预旋转**
 直升机Yaw弱，大角度时运用Roll+Pitch转向瞄准
 战斗机Yaw几乎无，优先Roll+Pitch机动

### 坦克等俯仰角有限
涂黑 角度限制外区域
