## 基于灭点几何的纯视觉 Pitch & Roll 解算算法

### 一、 算法物理原理

算法的底层依托于**曼哈顿世界假设（Manhattan World Assumption）**。在自然环境或人工建筑中，存在大量平行于重力方向的竖直线条（如树干、墙面边缘、承重柱）。

在针孔相机模型下，由于**透视畸变（Perspective Distortion）**，当相机发生俯仰（Pitch）和横滚（Roll）时，这些原本在 3D 空间中平行的竖直线，在 2D 图像屏幕上会发生倾斜，并最终交汇于一点（灭点 / 天底点）。

**降维打击的核心逻辑：**

1. 2D 屏幕上的一条直线，结合相机光心（原点），在 3D 空间中唯一确定了一个**切面（Plane）**。
    
2. 只要这根柱子在物理世界中是垂直的，那么这个 3D 切面**必定包含重力向量**。
    
3. 提取图像中两根不同位置的柱子，生成两个 3D 切面。这两个切面的**唯一交线**，就是重力向量 $\vec{G}$ 在相机坐标系下的真实指向。
    

### 二、 严谨数学推导

我们采用标准的计算机视觉坐标系（如 OpenCV）：

- **+X 轴**：指向画面右侧
    
- **+Y 轴**：指向画面下方（即**真实重力方向**）
    
- **+Z 轴**：指向画面正前方（相机光轴）
    

#### 1. 从 2D 像素到 3D 射线

已知相机内参焦距 $f$，以及图像中心点坐标 $(c_x, c_y)$。

图像上一根柱子的两个端点坐标为 $(u_1, v_1)$ 和 $(u_2, v_2)$。将它们逆投影为相机坐标系下的 3D 射线向量：

$$ \vec{r_1} = \left[ \frac{u_1 - c_x}{f}, \frac{v_1 - c_y}{f}, 1 \right]^T $$

$$ \vec{r_2} = \left[ \frac{u_2 - c_x}{f}, \frac{v_2 - c_y}{f}, 1 \right]^T $$

#### 2. 叉积求切面法向量

对射线的起点和终点向量求叉积，得到包含这根柱子的切面的法向量 $\vec{n}$：

$$ \vec{n} = \frac{\vec{r_1} \times \vec{r_2}}{||\vec{r_1} \times \vec{r_2}||} $$

#### 3. 叉积求重力向量

假设我们在图像中提取了两根柱子，分别求得它们的法向量为 $\vec{n_A}$ 和 $\vec{n_B}$。

这两个切面的交线即为重力向量 $\vec{G}$：

$$ \vec{G} = \frac{\vec{n_A} \times \vec{n_B}}{||\vec{n_A} \times \vec{n_B}||} $$

_物理约束校验_：重力必须指向地心（即相机的下方）。如果计算出的 $\vec{G}$ 的 $Y$ 分量小于 $0$，则说明向量指反了，需要做反向处理：

$$ \text{if } g_y < 0, \text{ then } \vec{G} = -\vec{G} $$

#### 4. 欧拉角逆解

在 Z-X-Y（Roll-Pitch-Yaw）顺规下，将世界坐标系（重力为 $[0, 1, 0]^T$）旋转到相机坐标系。重力向量 $\vec{G} = [g_x, g_y, g_z]^T$ 与欧拉角的关系解析解为：

$$ \vec{G} = \begin{bmatrix} \sin(\text{Roll}) \cos(\text{Pitch}) \\ \cos(\text{Roll}) \cos(\text{Pitch}) \\ -\sin(\text{Pitch}) \end{bmatrix} $$

根据上式直接反三角函数求解：

$$ \text{Roll} = \arctan2(g_x, g_y) $$

$$ \text{Pitch} = \arctan2(-g_z, \sqrt{g_x^2 + g_y^2}) $$

### 三、 C++ 工程源码实现

以下代码无需庞大的第三方库，仅依赖标准数学库。极度适合运行在 STM32 等飞控芯片或边缘端设备中。

C++

```
#include <iostream>
#include <cmath>
#include <vector>

// 简单的 3D 向量结构体
struct Vector3 {
    double x, y, z;
    
    // 向量叉积
    Vector3 cross(const Vector3& b) const {
        return {
            y * b.z - z * b.y,
            z * b.x - x * b.z,
            x * b.y - y * b.x
        };
    }
    
    // 向量归一化
    Vector3 normalize() const {
        double mag = std::sqrt(x*x + y*y + z*z);
        if (mag < 1e-6) return {0, 0, 0}; // 防止除零
        return {x/mag, y/mag, z/mag};
    }
};

// 2D 像素点结构体
struct Point2D {
    double u, v;
};

// 相机内参
struct CameraIntrinsics {
    double f;  // 焦距 (假设 fx = fy = f)
    double cx; // 光心 X
    double cy; // 光心 Y
};

/**
 * 视觉姿态解算核心函数
 * @param line1_p1 第一根竖直线的顶部端点
 * @param line1_p2 第一根竖直线的底部端点
 * @param line2_p1 第二根竖直线的顶部端点
 * @param line2_p2 第二根竖直线的底部端点
 * @param cam 相机内参
 * @param outPitch 输出 Pitch 角度 (度)
 * @param outRoll  输出 Roll 角度 (度)
 * @return 是否成功解算
 */
bool solvePitchRollFromVerticalLines(
    Point2D line1_p1, Point2D line1_p2,
    Point2D line2_p1, Point2D line2_p2,
    CameraIntrinsics cam,
    double& outPitch, double& outRoll) 
{
    // 1. 2D 像素逆投影为 3D 射线 (Z = 1 归一化平面)
    Vector3 r1_top = { (line1_p1.u - cam.cx) / cam.f, (line1_p1.v - cam.cy) / cam.f, 1.0 };
    Vector3 r1_bot = { (line1_p2.u - cam.cx) / cam.f, (line1_p2.v - cam.cy) / cam.f, 1.0 };
    
    Vector3 r2_top = { (line2_p1.u - cam.cx) / cam.f, (line2_p1.v - cam.cy) / cam.f, 1.0 };
    Vector3 r2_bot = { (line2_p2.u - cam.cx) / cam.f, (line2_p2.v - cam.cy) / cam.f, 1.0 };

    // 2. 叉积求切面法向量
    Vector3 n1 = r1_top.cross(r1_bot).normalize();
    Vector3 n2 = r2_top.cross(r2_bot).normalize();

    // 检查两根线是否在 2D 画面上几乎共线（叉积结果趋近于零向量）
    Vector3 G = n1.cross(n2);
    double mag = std::sqrt(G.x*G.x + G.y*G.y + G.z*G.z);
    if (mag < 1e-5) {
        return false; // 两条线共线或平行度极高，无法构成空间相交，解算失败
    }
    
    // 3. 得到重力向量并校验物理方向
    G = G.normalize();
    if (G.y < 0) {
        G.x = -G.x;
        G.y = -G.y;
        G.z = -G.z;
    }

    // 4. 解析欧拉角 (弧度转角度)
    const double RAD2DEG = 180.0 / M_PI;
    outRoll = std::atan2(G.x, G.y) * RAD2DEG;
    outPitch = std::atan2(-G.z, std::sqrt(G.x*G.x + G.y*G.y)) * RAD2DEG;

    return true;
}

// ================= 测试用例 =================
int main() {
    CameraIntrinsics cam = { 400.0, 320.0, 240.0 }; // 以 640x480 分辨率为例
    
    // 模拟检测到的两根竖直线坐标 (发生透视畸变后的坐标)
    Point2D l1_top = { 200.5, 100.0 };
    Point2D l1_bot = { 250.0, 400.0 };
    
    Point2D l2_top = { 400.0, 120.0 };
    Point2D l2_bot = { 380.0, 380.0 };
    
    double pitch = 0.0, roll = 0.0;
    
    if (solvePitchRollFromVerticalLines(l1_top, l1_bot, l2_top, l2_bot, cam, pitch, roll)) {
        std::cout << "解算成功!" << std::endl;
        std::cout << "Pitch: " << pitch << "°" << std::endl;
        std::cout << "Roll:  " << roll << "°" << std::endl;
    } else {
        std::cout << "解算失败：线条共线或有效几何特征不足。" << std::endl;
    }

    return 0;
}
```

### 四、 避坑指南（最佳实践）

1. **直线提取前置处理**：在输入算法前，务必使用 LSD（Line Segment Detector）或者基于梯度的直线检测。长度过短（如小于 30 像素）的线段由于像素离散化误差，会极大地污染法向量，应当直接剔除。
    
2. **多线段加权融合（SVD 优化）**：如果画面中存在 3 根以上的柱子，不要只挑两根算。应将所有线段求出的法向量矩阵 $A = [\vec{n_1}, \vec{n_2}, ... , \vec{n_k}]^T$ 拼接，然后利用 **SVD（奇异值分解）** 求 $A^T A$ 最小特征值对应的特征向量，这才是全局最优的重力向量 $\vec{G}$，抗噪能力直接翻倍。
