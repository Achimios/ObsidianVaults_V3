## 3. 本轮编者问题：不属于原作者已写出的结论

需要分别问四个问题：压缩什么对象；允许丢失什么；用什么描述语言；要求保留什么任务能力。“符号有限”“一个描述有限”“程序运行步数有限”也不是同一条件。

原稿把可证明性、可计算性、可压缩性与混沌放在一句话里。本轮不直接把这句话当作它们之间的定理。首轮辨析见 [核验与反例 C01](02_核验与反例.md#c01)。

## 4. 与本轮直觉讨论的关系：候选连接

当前对话补进了一个方向：在有限时间里处理高带宽输入时，不必追求逐点复原整个世界，而应问保留哪些信息才能支持任务。它可与“压缩”对话，但不等于原稿已提出信息瓶颈理论，也不等于压缩率就是智力。
